# Security policy

## Reporting a vulnerability

Please do not disclose security issues, keys, tokens, account data or private server information in a public issue.

Use GitHub's private security-reporting channel for this repository when it is available, or contact the project maintainer privately. Include a clear reproduction, affected version and impact. Do not attach real account sessions or credentials.

## Repository safety

The repository intentionally excludes private build configuration, signing keys, server state, administrator data and release APK files. If you believe a credential was committed, report it privately and rotate the credential immediately.
