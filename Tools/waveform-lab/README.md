# Waveform Lab

Откройте **index.html** двойным щелчком. Стенд работает без интернета и сервера.

Оставлены только шесть выбранных компактных заготовок: **Бриллиант,
Бабочка, Бантик, Стрела, Рыба, Песочные часы**. Их формы и исходная ширина
совпадают с компактными вариантами из тестовой галереи. Рыба направлена
вправо, песочные часы повёрнуты на 90°. Нажатие на карточку открывает её
в редакторе. Все остальные заготовки и широкие варианты удалены.

Редактор увеличен по высоте для удобства рисования. Предпросмотр сохраняет
реальные пропорции стандартных полосок Telegram: шаг 3 dp, толщина 2 dp,
высота 2–16 dp. Масштаб увеличивает обе оси одинаково. В галерее показаны
одни и те же компактные данные при ширине сообщения 120, 180 и 240 dp.

Рисуйте мышью, отменяйте изменения, сохраняйте и открывайте JSON,
экспортируйте SVG. Экспериментальное смещение верхнего и нижнего края
не сохраняется в обычных симметричных полосках Telegram.

**approved-presets.js** — единственный источник шести заготовок.
`node generate-presets.cjs` обновляет **optimized.js** и Android-класс
**WaveformPresets.java**. `node tests.cjs` сравнивает с настоящими Java-классами
упаковку, чтение и заготовки. Для генерации нужны исходники проекта,
для проверок — также Node.js и JDK.

Проверки сайта: `node dev/ui-check.cjs` и `node dev/gallery-check.cjs`.
Они используют локально установленный Playwright и Chrome.
