Новое обновление

Загрузите APK, подпись которого совпадает с вашим приложением. Сначала создаётся черновик; пользователи увидят его после публикации. Максимум 200 МБ.

Галочки AstraGram

Укажите числовой Telegram ID, а не @username. По умолчанию выдаётся галочка за поддержку. Смена типа и отзыв применяются в клиентах при следующей проверке.

Проверка ключей

При выключении новые версии пропускают пользователя без ключа после получения подписанной настройки сервера. Настройка проверяется при запуске и затем регулярно; сохранённый ответ действует до 24 часов. Старые APK этот режим не поддерживают.
