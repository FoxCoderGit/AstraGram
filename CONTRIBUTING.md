# Contributing to AstraGram

Thank you for helping improve AstraGram.

## Before opening an issue

1. Install the latest release and check whether the problem still occurs.
2. Search existing issues to avoid duplicates.
3. Include the AstraGram version, Android version, device model, reproducible steps and the expected and actual result.
4. Remove personal data from screenshots and logs.

Do not publish API hashes, passwords, session exports, Yandex tokens, administrator credentials, signing files or private chat content.

## Pull requests

- Keep each change focused and explain the user-visible effect.
- Build the affected module before submitting a pull request.
- Preserve compatibility with the supported Android versions and existing application data.
- Do not commit generated build output, APK files or private configuration files.

## Feature requests

Describe the problem being solved, the intended behaviour and any privacy or service-provider implications. Features that require an external account must use each user’s own authorization rather than a shared credential.
